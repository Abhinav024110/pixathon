# ✳️ Human Check: The Vibe Check CAPTCHA

> **A tiny retro arcade cabinet built for Pixathon.**  
> *Prove you are human by surviving 8 funny, instinctual, everyday mini-challenges.*

---

## 🎮 Playable Puzzles

1. **Earbud Escape:** Untangle a headphone cable by tracing an SVG path without taking shortcuts.
2. **Elevator Diplomacy:** Press and hold the button until the doors open. (The elevator senses hesitation.)
3. **The Rewind Spiral:** Drag the playhead back to hit the chorus (not 1998).
4. **Paparazzi Panic:** Catch a runaway camera 5 times before it takes unflattering candids.
5. **Midnight Microwave:** Stop the microwave timer in the yellow zone before the beep wakes the household.
6. **The Goodbye Spiral:** Close 5 "one last thing..." pop-ups to escape a long conversation.
7. **Voice-Note Consequences:** Type a quick phrase verbatim before your thumbs panic under pressure.
8. **Chore-Dodging Final Boss:** Dodge falling laundry for 12 seconds to push your chores to tomorrow.

---

## 🕹️ Controls

* **Mouse / Touch:** Drag sliders, trace paths, click moving targets, and hold buttons.
* **Keyboard Support:** Arrow keys (Left/Right) for Level 8 (Chore Dodger) and Level 1 (Cable Tracing). Space / Enter for button holding.

---

## 🛠️ Technical Details

* **Stack:** Pure Single-File HTML5 / CSS3 / Vanilla JavaScript (`index.html`).
* **Styling:** Custom CSS Monospace & Pixelated Theme (`Lucida Console`), hard offset box-shadows, dynamic color system.
* **Graphics:** Inline SVG path geometry + Pure CSS pixel-art mascot.
* **Dependencies:** None. Run instantly in any web browser.
